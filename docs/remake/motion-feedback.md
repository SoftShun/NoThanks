# 모션 · 피드백 명세

구현: 타이밍 토큰 `web/src/anim/motion.ts`, 단일 큐 `web/src/anim/queue.ts`, 연출 `web/src/table/TableView.ts`, 효과음 `web/src/fx/sound.ts`, 진동 `web/src/fx/haptics.ts`.

## 1. 원칙

| 원칙 | 구현 |
|---|---|
| 입력 100ms 안 반응 | 버튼 `:active` 축소(60ms) + 흰 플래시 + 효과음·진동을 **클릭 핸들러 안에서 동기 실행**, 예측 연출도 같은 프레임에 시작(낙관적 반응). 측정값은 acceptance.md |
| 서버 거절 시 롤백 | 칩/카드가 되돌아가는 연출(200ms) → 버튼 흔들림(260ms) → 토스트 |
| 단일 애니메이션 큐 | 모든 게임 이벤트 연출은 `AnimationQueue` 하나에서 순서대로. 연출이 끝나야 다음 이벤트. 상태(HUD)는 연출 시작 시 갱신 |
| 밀림 따라잡기 | 대기 2개 이상 → 1.4배속, 4개 이상 → 2.2배속 (`gsap.globalTimeline.timeScale`) |
| 60fps | GSAP 은 transform/alpha 만 트윈, Pixi Graphics 는 상태 변경 시에만 다시 그림, 점수 화면이 덮으면 Pixi 렌더 정지 |
| 지연 300ms 대응 | 내 행동은 예측으로 즉시 끝나고, 서버 결과(다음 카드)는 카드 이동 연출(360ms)이 지연을 가림 |

## 3. 모션 줄이기 (`prefers-reduced-motion` / 설정)

| 연출 | 일반 | 줄이기 |
|---|---|---|
| 카드·칩 이동 | 위 표 | 이동 없이 즉시 배치 + 120ms 페이드 |
| 흔들림·반짝이·셔플·탄성 | 있음 | 없음 |
| 점수 팝업 | 상승 | 제자리 표시 후 사라짐 |
| 점수 집계 | 카운트업 | 즉시 최종값 |
| CSS 애니메이션 | 있음 | 1ms |
| 큐 순서 보장 | 유지 | 유지 |

설정: 시스템(기본) / 전체 / 줄이기. OS 설정 변경을 실시간 반영.

## 4. 효과음 목록 (임시음 — jsfxr 런타임 합성)

| 키 | 언제 | 파형 | 느낌 | 최종음 방향 |
|---|---|---|---|---|
| `tap` | 버튼·설정 조작, 히든 가져가기 입력 | 사인 | 짧은 똑 | 나무 카운터 톡 |
| `flip` | 카드 공개 | 노이즈 | 종이 넘김 | 두꺼운 종이 슥 |
| `chip` | 칩 걸기 | 사각 + 아르페지오 | 짤랑 | 엽전 하나 놓는 소리 |
| `take` | 카드 가져가기 | 톱니 상승 | 휙 | 종이 끌어오기 |
| `coins` | 쌓인 칩 획득 | 사각 아르페지오 | 짤랑짤랑 | 엽전 여러 개 쓸어 담기 |
| `turn` | 내 차례 | 사인 아르페지오 | 딩 | 작은 종 |
| `error` | 거절·차례 아님 | 사각 하강 | 부웅 | 낮은 둔탁음 |
| `tick` | 점수 카운트 | 사인 고음 | 틱 | 주판알 |
| `win` | 1등 | 사각 + 비브라토 | 팡파르 | 짧은 징 + 동전 |
| `shuffle` | 게임 시작 | 노이즈 반복 | 촤라락 | 카드 섞기 |
| `reveal` | 히든 공개 | 사인 + 비브라토 | 신비 | 종이 펼침 + 반짝 |

- 첫 사용자 입력 때 합성(자동재생 정책), Howler.js 로 재생. 설정에서 끄기 / `M` 키 / 설정 시트에서 미리 듣기.
- 교체: `sound.ts` 의 키는 유지하고 `src` 만 파일로 바꾸면 됨.
