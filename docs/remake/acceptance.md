# 수락 기준 체크리스트 + 웹 vs Unity 비교표

- 측정일: 2026-11-25 · 측정 원자료: [`measure-web.json`](./measure-web.json) · 재측정: `web/` 에서 `npm run build && npm run preview` 후 `BASE_URL=http://localhost:4173 npm run measure`
- **측정 환경 주의**: 리눅스 클라우드 컨테이너, CPU 4코어, **GPU 없음**(헤드리스 크로미움 + SwiftShader 소프트웨어 GL). 네트워크는 localhost. 실제 맥/휴대폰 수치는 아래 표의 "맥에서 재측정" 칸을 채워 비교할 것.

표기: ✅ 확인함 · ⚠️ 부분 확인/조건부 · ❌ 미충족 · ⬜ 이 환경에서 확인 불가(맥·실기기 필요)

### 스크린샷을 보고 고친 것

| 발견 | 수정 |
|---|---|
| 세로 로비: 패널이 화면 오른쪽 밖으로 넘침 | 그리드 `minmax(0,1fr)`, 세그먼트 최소폭 축소 |
| 세로 게임: 손패 상자 아래 빈 공간, 카드가 작음 | 손패를 바닥에 붙이고 남는 높이를 가운데 카드에 배분(`anchorHand`) |
| 묶음 카드의 숫자가 겹쳐 가려짐(테이블·결과 모두) | 가장 낮은 카드를 맨 위로, 나머지는 오른쪽 정렬 숫자 + z-순서 역전 |
| 상대 미니카드 15px 로 판독 불가 | 18~19px 로 확대 |
| 결과 설명이 줄바꿈되어 "니/다." 로 끊김, "나 (나)" 중복 | 문구 단축, 본인 표시는 태그로 |
| 가로 로비: 하단 고정 버튼이 설정을 가림 | 시작 버튼을 헤더로 이동 |
| 1920 결과 화면 집계 연출이 끝나지 않음 | 결과 화면이 덮으면 Pixi 렌더 정지, 요청 기반 렌더 도입 |

### 첫 로딩 (캐시 없음, 5회 중앙값 / Fast 3G 는 3회)

| 조건 | DOMContentLoaded | 첫 화면(FCP) | 로비 조작 가능 + 폰트 준비 | 전송량 | 시작 → 테이블 준비 |
|---|---|---|---|---|---|
| 데스크톱 1440, localhost | 50 ms | – (헤드리스 미보고) | **193 ms** | 489 KB / 17 요청 | 654 ms |
| 모바일 390, localhost | 57 ms | 72 ms | **223 ms** | 489 KB | 608 ms |
| 모바일 390, Fast 3G 에뮬(1.6Mbps, RTT 150ms) | 1,053 ms | 1,072 ms | **2,972 ms** | 489 KB | 1,302 ms |

> 489 KB 중 약 340 KB 가 한글 폰트 서브셋. 개선 여지: 로비 글자만 미리 서브셋, 굵기 수 축소.

### FPS · 입력 반응

| 항목 | 데스크톱 1440 | 모바일 390 (DPR 2) | 비고 |
|---|---|---|---|
| 정지 화면 FPS | 51.5 | 60.5 | 요청 기반 렌더로 정지 시 렌더 0회 |
| 연출 중 평균 FPS | 17.9 | 12.1 | ⬜ **SwiftShader 소프트웨어 래스터 한계**. 빈 WebGL 은 60fps |
| 렌더 호출 메인스레드 시간 | 0.5 ms / p95 2.7 ms | 0.6 ms / p95 2.7 ms | 16.7ms 예산 대비 여유 큼 |

| 목 서버 지연 | 입력 → 첫 프레임 중앙값 | p95 | 서버 확인(ack)까지 중앙값* |
|---|---|---|---|
| 0 ms | **80 ms** | 165 ms | 395 ms |
| 100 ms | **84 ms** | 138 ms | 323 ms |
| 300 ms | **81 ms** | 142 ms | 522 ms |

\* Playwright 폴링 오버헤드 포함 참고값. 입력→첫 프레임은 `event.timeStamp` → 두 번째 `requestAnimationFrame`(화면 반영 후) 기준. 지연이 커져도 반응 시간이 같다 = 낙관적 반응이 동작함.

## 5. 확인하지 못한 것 (맥·실기기에서 볼 것)

| 항목 | 이유 | 맥에서 확인 방법 |
|---|---|---|
| 연출 중 60fps | 컨테이너에 GPU 없음 | 설정 → "성능 표시" 켜고 한 판 진행, `FPS`/`렌더/s` 확인. 또는 `npm run measure` |
| 효과음 실제 음색 | 헤드리스 | 설정 → 효과음 미리 듣기 |
| 햅틱 | 실기기 없음 | 안드로이드 크롬으로 접속(iOS 는 미지원) |
| 노치·홈 인디케이터 safe area | 실기기 없음 | 아이폰 사파리로 접속, 가로/세로 회전 |
| 실제 터치 조작감 | 에뮬레이션만 | 휴대폰으로 지연 300ms 설정 후 플레이 |
