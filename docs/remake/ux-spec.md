# UX 명세 — 화면별 배치와 브레이크포인트

기준 해상도 4개를 **각각 다른 배치**로 만든다(비율만 늘리고 줄이지 않음).
구현: 모드 판정 `web/src/app/config.ts layoutModeFor()`, DOM 배치 `web/src/ui/styles.css`(`.mode-*`), 테이블 배치 `web/src/table/TableView.ts computeGeo()/anchorHand()`.

## 1. 브레이크포인트

| 모드 | 판정 (CSS px, 창 크기) | 기준 해상도 | 대표 기기 |
|---|---|---|---|
| `portrait` | 세로가 더 길고 너비 < 600 (또는 너비 < 900 인 세로) | 390×844 | 폰 세로 |
| `landscape` | 가로가 더 길고 높이 < 560 | 844×390 | 폰 가로 |
| `desktop` | 그 외 | 1440×900 | 노트북, 태블릿 가로 |
| `wide` | 너비 ≥ 1680 이고 높이 ≥ 940 | 1920×1080 | 데스크톱 모니터 |

- 창 크기가 바뀌면 즉시 다시 판정(`resize`, `visualViewport.resize`). 높이는 `--vh` 로 실제 보이는 높이를 씀(모바일 주소창 대응).
- 공통: 터치 대상 최소 **44×44px**(`--tap`), 주 행동 버튼은 **56~68px** 높이. `viewport-fit=cover` + `env(safe-area-inset-*)` 로 노치·홈 인디케이터 영역 회피.

### 2-2. 모바일 가로 844×390 — "양손, 오른손 엄지로 결정"

```
┌──────────────────────────────────────────────┬──────────────┐
│ (AI) 봇1 칩?  ▯▯▯                             │ ● {새 이름} ≡ │
│                     ┌──┐  ┌─────┐◎×8          │ [덱 9]        │
│ (AI) 봇2 칩?  ▯▯ ▯   │덱│  │ 21  │             │ ◎12  점수 19  │
│                     └──┘  └─────┘             │ 내 차례 — …   │
│ (AI) 봇3 칩?  ▯                                │ ▬▬▬▬▬▬ 타이머  │
│               ┌───────────────────────────┐  │ [  칩 걸기  ] │
│               │ 내 카드 3장 ▯8▯ ▯23▯        │  │ [  가져가기  ] │
└───────────────┴───────────────────────────┴──┴──────────────┘
  ↑ safe-left(노치)                               228px, safe-right
```
- 상대는 왼쪽 세로 열(가로형 좌석: 아바타·이름·칩 옆에 손패).
- 버튼은 오른쪽 열에 위아래로 → 오른손 엄지 도달 범위. HUD 도 오른쪽 열로 옮겨 테이블 높이를 최대로.
- 로비: 2열 + "게임 시작" 버튼을 헤더 오른쪽에(스크롤 없이 바로 시작).

### 2-3. 데스크톱 1440×900 — "마우스 + 키보드"

```
┌─────────────────────────────────────────────┬───────────────┐
│ ● {새 이름}                    [덱][제외]  ≡ │ 플레이어(턴순)  │
├─────────────────────────────────────────────┤  ● 나  칩20 30점│
│        (AI)      (AI) ← 위쪽 호(arc)  (AI)   │  ● 봇1 칩?  0+ │
│        ▯▯        ▯▯▯▯          ▯▯           │                │
│   ╭──────────── 타원 테이블 ─────────────╮   │ 진행 기록        │
│   │        ┌───┐   ┌──────┐ ◎×5          │   │ #63 카드 11 공개 │
│   │        │덱 │   │  35  │              │   │ #65 봇3: 11 …   │
│   │        └───┘   └──────┘              │   │ …              │
│   │   ┌──────── 내 카드 ────────┐          │   │                │
│   ╰───┴─────────────────────────┴────────╯   │ 단축키          │
├─────────────────────────────────────────────┤  Space/P 칩 걸기 │
│ ◎20 점수30        내 차례 — …   [칩 걸기 ␣][가져가기 ⏎] │ Enter/T 가져가기│
└─────────────────────────────────────────────┴───────────────┘
                                                  340px
```
- **hover**: 상대 좌석 → 툴팁(난이도, 카드 점수, 묶음, 칩·현재 점수) / 가운데 카드 → 카드 살짝 확대 + "가져가기" 버튼 테두리 강조 / 모든 버튼 밝기 변화.
- **키보드**: `Space`·`P`·`←` 칩 걸기, `Enter`·`T`·`→` 가져가기, `M` 소리, `Esc` 설정. 버튼에 `<kbd>` 표시, `aria-keyshortcuts` 지정.

## 3. 로비·결과 화면

| 화면 | portrait | landscape | desktop | wide |
|---|---|---|---|---|
| 로비 | 1열 스크롤, 하단 고정 "게임 시작"(56px) | 2열(참가자 / 설정), 옵션은 아래 전체 폭, 시작 버튼은 헤더 | 2열 + 옵션 전체 폭, 최대 1100px 가운데 | 3열(참가자 / 설정 / 옵션), 최대 1440px |
| 결과 | 세로 카드 목록(이름 줄 + 손패 줄) | 한 줄 행(순위·이름·손패·카드·칩·최종) | 한 줄 행, 760px 시트 | 한 줄 행, 980px 시트 |

## 4. 상태·피드백 규칙

| 상황 | 표시 |
|---|---|
| 내 차례 | 액션바 위 테두리 놋쇠 + 발광, 손패 상자 테두리 발광, 버튼 올라오는 연출, "내 차례 —" 문구, 효과음·진동 |
| 남의 차례 | 버튼 비활성(38% 불투명), "봇 이름 생각 중…" 점 애니메이션, 해당 좌석 링 |
| 칩 0개 | "칩 걸기" 비활성 + "칩 없음", 상태 문구 "칩이 없습니다 — 가져가야 합니다" |
| 결과 미리보기 | 가져가기 버튼 아래 `+N점 · 칩 +M`(연결 묶음 반영), 칩 걸기 버튼 아래 `칩 −1 · 남은 칩 K` |
| 턴 제한 | 내 차례에만 진행 막대, 5초 미만이면 주홍색 |
| 거절 | 버튼 흔들림 + 토스트 + 오류음 + 진동, 화면 상태 롤백 |
| 히든 카드 | 뒷면에 `?`, 가져가기 문구 "공개 후 가져감", 공개 중 버튼 잠금 |

## 5. 접근성

| 항목 | 처리 |
|---|---|
| 대비 | 본문 13:1, 보조 5.6:1 이상 |
| 포커스 | `:focus-visible` 놋쇠 외곽선 |
| 스크린리더 | 상태 문구 `aria-live="polite"`, 토스트 `assertive`, 스위치 `role="switch"`, 세그먼트 `role="radiogroup"` |
| 모션 | `prefers-reduced-motion` + 설정에서 강제(시스템/전체/줄이기) |
