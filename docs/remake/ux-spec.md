# UX 명세 — 화면별 배치와 브레이크포인트

> 단위는 모두 **논리 px** (웹: CSS px, 휴대폰: dp). WebGL 에서는 `devicePixelRatio` 를 UI Toolkit 패널 배율로 써서 390×844 아이폰이 정확히 390×844 논리 px 가 된다. 에디터에서는 배율 1 (Game 뷰 해상도 = 논리 px).
> 레이아웃은 **4개의 서로 다른 트리**로 만든다 (`GameScreen.BuildPortrait/BuildLandscape/BuildDesktop`). 같은 트리를 늘리거나 줄이지 않는다.

## 1. 브레이크포인트

| 레이아웃 | 판정 (`LayoutRules.Decide`) | 기준 해상도 | 주 입력 |
|---|---|---|---|
| `Portrait` (모바일 세로) | 높이 ≥ 너비 | **390×844** | 터치 (엄지 하단) |
| `LandscapeCompact` (모바일 가로) | 너비 > 높이 그리고 높이 < 560 | **844×390** | 터치 (양손 엄지) |
| `Desktop` | 그 외 | **1440×900** | 마우스 + 키보드 |
| `DesktopWide` | 너비 ≥ 1700 그리고 높이 ≥ 950 | **1920×1080** | 마우스 + 키보드 |

창 크기·방향·DPR·safe area 가 바뀌면 매 프레임 감지해 즉시 다시 만든다(진행 상태·기록은 유지).

## 2. 레이아웃별 치수 (`LayoutSpec`)

| 항목 | 세로 390×844 | 가로 844×390 | 1440×900 | 1920×1080 |
|---|---|---|---|---|
| 중앙 카드 | 140×196 | 100×140 | 176×246 | 216×302 |

### 3-4. 로비
| 레이아웃 | 배치 |
|---|---|
| 세로 | 스크롤 1열: 제목 → 카드 3장 부채꼴 → 설정 섹션들 / 하단 고정 "게임 시작"(62) |
| 가로 | 왼쪽 300: 제목 + 시작 버튼 / 오른쪽: 설정 스크롤 |
| 데스크톱 | 가운데 2열: 왼쪽 제목·데코·시작(360×68, Enter) / 오른쪽 설정 카드(520~620, 스크롤) |

### 3-5. 결과
| 레이아웃 | 배치 |
|---|---|
| 공통 | "결과" 제목 → 순위 행(1위부터) → 하단 [다시 하기] [로비로] |
| 순위 행 | 순위 · 이름 · (카드 N − 칩 M) · 최종 점수, 아래 손패 묶음 |
| 데스크톱 | 최대 폭 900, 버튼에 Enter / Esc 표시 |

## 4. 터치 타깃 · safe area

| 규칙 | 구현 |
|---|---|
| 모든 누를 수 있는 요소 ≥ 44×44 | `ActionButton` `minHeight/minWidth 44`, `Pill` 높이 44·최소폭 52, `Stepper` −/+ 44×44, 메뉴·지연 배지 44 |
| 주요 행동 버튼은 60 이상 | 세로 60, 가로 58/66, 데스크톱 64/72 |
| 버튼 사이 간격 ≥ 10 | 패스–가져가기 10 |
| safe area | 루트 패딩 = 인셋. WebGL: CSS `env(safe-area-inset-*)` 를 jslib 로 읽음(템플릿 `viewport-fit=cover`). 네이티브: `Screen.safeArea` |
| 브라우저 제스처 차단 | 템플릿 CSS `touch-action:none`, `overscroll-behavior:none`, 선택·탭 하이라이트 끔 |

## 5. 데스크톱 hover · 키보드

| 입력 | 동작 |
|---|---|
| hover: 버튼 | 밝아지고 2px 떠오름 (단축키 힌트는 버튼 오른쪽 위에 항상 표시) |
| hover: 상대 좌석 | 테두리 전체 강조 (런타임 UI Toolkit 은 툴팁을 그리지 않으므로 툴팁은 쓰지 않음) |
| `Enter` / `T` / 숫자패드 Enter | 가져가기 |
| `Space` / `P` | 패스 (칩 0개면 흔들림 + 안내) |
| `Esc` | 메뉴 열기/닫기 · 결과 화면에서 로비 |
| `M` | 소리 켜기/끄기 |
| `F3` (또는 지연 배지 클릭) | 성능 표시 (fps, 1% low, 입력→반응 ms, 큐 길이, 롤백/보정 횟수, 로드 시간) |
| `1` `2` `3` | 지연 0 / 100 / 300ms 즉시 전환 |
| 로비 `Enter` | 게임 시작 |

## 6. 상태 표현

| 상황 | 표현 |
|---|---|
| 내 차례 | 턴 라벨 황동색 "내 차례" + 좌석 링 + 버튼 떠오름 + 효과음 + 햅틱(가볍게) |
| 내 차례 아님 | 버튼 45% 투명·비활성, 턴 라벨 "○○의 차례" |
| 가져가기 미리보기 | 버튼 아래 "+칩 N · 점수 ±X" (공개 정보로 계산) |
| 패스 미리보기 | "칩 1개 지불 (남은 N)" / 칩 0개 "칩이 없어 패스 불가" |
| 턴 제한 | 무대 위 타이머 바, 5초 이하 적색 + 초마다 틱 |
| 숨김 카드 | 뒷면 + `?`, 가져가기 누르면 흔들림 → 뒤집힘 → "숨김 카드 공개!" |
| 서버 거절 | 적색 토스트 + 좌석 흔들림 + 되돌리기 연출 + 오류음 + 햅틱 |
| 상대 칩 비공개 | `●?`, 점수는 "카드 N점" 으로만 |
